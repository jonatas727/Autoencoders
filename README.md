# Autoencoders

Segundo trabalho desenvolvido na disciplina de Redes Neurais e Algoritmos Genéticos da Ilum.
O projeto apresenta uma introdução teórica aos Autoencoders, além de aplicações práticas envolvendo reconstrução de imagens e comparação com métodos clássicos de redução de dimensionalidade.

---

## Estrutura do Projeto

### Autoencoders.pdf

Documento principal do trabalho.

Contém:

- introdução teórica aos autoencoders;
- explicação da arquitetura e funcionamento;
- discussão sobre aprendizado não supervisionado;
- comparação conceitual com PCA;
- análise dos resultados obtidos nos experimentos.

A seção final antes das referências discute os resultados gerados pelo arquivo `Autoencoders_PCA_estudo.py`, detalhados também no notebook `Autoencoders_PCA_estudo.ipynb`.

---

### Autoencoders_PCA_estudo.ipynb

Notebook com um estudo comparativo entre:

- PCA (Principal Component Analysis);
- Autoencoders como técnica de redução de dimensionalidade.

O notebook apresenta:

- preparação dos dados;
- treinamento dos modelos;
- análise de desempenho;
- interpretação dos resultados.

---

### Autoencoders_PCA_estudo.py

Arquivo contendo a implementação principal do estudo comparativo entre PCA e Autoencoders.

Responsável por:

- executar os experimentos;
- treinar os modelos;
- gerar os resultados analisados no arquivo PDF.

---

### Implementacao_didatica_pytorch.ipynb

Implementação didática de um autoencoder em PyTorch utilizando o dataset MNIST.

O notebook demonstra:

- construção da arquitetura;
- treinamento do modelo;
- reconstrução de imagens manuscritas;
- visualização dos resultados.

---

- Introduzir os conceitos fundamentais de autoencoders;

- Demonstrar aplicações práticas com Redes Neurais do tipo Autoencoders.
